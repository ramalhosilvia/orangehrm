# OrangeHRM – Automated Testing

UI test automation for OrangeHRM (https://opensource-demo.orangehrmlive.com/), developed as part of a QA technical task using Cypress and Page Object Model.


## Requirements
- Node.js 24.22.2
- Cypress 15.7.1
- Google Chrome


## Setup
Install the dependencies:

```bash
npm ci
```

Create a `cypress.env.json` file in the project root:

```json
{
  "username": "Admin",
  "password": "admin123"
}
```

This file is excluded from version control.


## Run
Open the Cypress interface:

```bash
npx cypress open
```

Run all tests in headless mode using Chrome:

```bash
npx cypress run --browser chrome
```


## Specs
- **`cypress/e2e/login.cy.js`** — Verifies successful login and error handling for invalid credentials, empty fields, and credentials containing only spaces.
- **`cypress/e2e/employee.cy.js`** — Creates an employee, captures the Employee ID generated by OrangeHRM, searches for the employee, updates personal and job details, verifies the changes, and deletes the employee.
- **`cypress/e2e/report.cy.js`** — Creates another employee, adds an emergency contact’s mobile number, generates a PIM report, verifies that the report displays the expected number, and deletes the report and employee.


## Design
Page Objects keep selectors and page interactions separate from the test scenarios. Generated employee data and captured IDs are reused throughout each workflow to identify the correct records.
